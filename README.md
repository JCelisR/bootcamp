📁 Proyectos Destacados
En este repositorio se encuentran los hitos principales de mi formación en el Bootcamp de Ciencia de Datos:

M8: StyleNet - Clasificación de Moda con Deep Learning
Tecnologías: PyTorch, Torchvision, Redes Neuronales Convolucionales (CNN).
Descripción: Desarrollo de un modelo de visión artificial para clasificar imágenes de prendas (Fashion-MNIST) con una precisión superior al 85%.

M7: Segmentador Inteligente de Clientes
Tecnologías: Scikit-Learn (K-Means), PCA, t-SNE, Seaborn.

M6: Predictor de Gasto E-commerce
Tecnologías: Pandas, Scikit-Learn (Gradient Boosting), Tratamiento de Outliers (IQR).
Descripción: Pipeline integral para predecir el gasto de clientes, optimizando el rendimiento mediante la depuración avanzada de datos anómalos.
